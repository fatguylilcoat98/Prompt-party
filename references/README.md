# Visual references

The build brief names `references/flint_show_visual_show.html` as the
visual-direction reference (separate Overview, Lobby, Shared System,
Broadcast, Audience, Producer, and per-game views).

**Deviation record (Milestone 1):** that HTML file was not present in the
supplied materials, this repository, or any accessible sibling repository
at build time. The Master Spec (section 3, "Product Surfaces") describes
the same view separation and is being used as the authoritative substitute
until the file is provided. Drop the file in this directory when
available; no code depends on it.
